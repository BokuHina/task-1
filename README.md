#ЗАПУСК ОНОВЛЕНОЇ СОРУКТУРИ

**як запустити API:**
потрібно прописати базову команду для запуску веб-сервера ( uvicorn main:app --reload), але тепер заміть main ми повинні прописати ще і шлях з кореневого каталога до файла з API
```bash
uvicorn -m src.visual_shells.main:app --reload
```

**як запустити CLI:**
запуск майже не змінився, просто теж потрібно вказувати шлях з кореневого каталогу і вказати команду для виконання (флаг -m потрібен для запуску модуля як частини пакету)
```bash
python -m src.visual_shells.cli list-trips
```

**як запустити playground:**
playground запускається просто вказанням повного шляху та назви файла
```bash
python -m src.visual_shells.playground_sqlite     
```
