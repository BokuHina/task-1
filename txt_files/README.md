# ОПИС ПРОЄКТУ
У цому завданні було реалізовано 5 коман, команди та результати їх виконання:
**add** додає у бд поїздку
 ```bash
python cli.py add -from A-City -to B-City -dt 01:30 -st 3 -p 260 -dn Kondrat
Поїздка A-City -> B-City Час:01:30  додана успішно.
```

**list-trips** показує список усіх поїздок 
 ```bash
python cli.py list-trips
[1] Kiyv -> Lviv, час: 10:00, вільних місць: 0/15, ціна: 500.0
[2] Odessa -> Harkiv, час: 12:00, вільних місць: 4/30, ціна: 800.0
[3] Odessa -> Kiyv, час: 14:00, вільних місць: 0/20, ціна: 600.0
[4] Lviv -> Kiyv, час: 16:00, вільних місць: 0/10, ціна: 550.0
[5] Harkiv -> Odessa, час: 18:00, вільних місць: 0/25, ціна: 750.0
[6] Lviv -> Odessa, час: 20:00, вільних місць: 0/18, ціна: 700.0
[7] Kiyv -> Harkiv, час: 22:00, вільних місць: 0/12, ціна: 650.0
[8] Harkiv -> Lviv, час: 09:00, вільних місць: 0/22, ціна: 720.0
[9] TestCityA -> TestCityB, час: 15:30, вільних місць: 5/20, ціна: 450.0
[10] A-City -> B-City, час: 01:30, вільних місць: 0/3, ціна: 260.0
```

**search-trip** шукає поїздки по місцю відправлення/прибуття (вказувати параметри не обов'язково)
 ```bash
python cli.py search-trip -f Lviv  
[4] Lviv -> Kiyv, час: 16:00, вільних місць: 0/10, ціна: 550.0
[6] Lviv -> Odessa, час: 20:00, вільних місць: 0/18, ціна: 700.0
```

**book-seat** бронює місце у поїздці з ваказаним ID
 ```bash
python cli.py book-seat 10
Місце у поїздці з ID 10 успішно заброньовано.
```
якщо місць не вистачає буде повідомлення:
 ```bash
python cli.py book-seat 10
Не вдалося забронювати місце: в поїздці з ID 10 немає вільних місць.
```

**cancel-book** скасовує бронювання місця 
 ```bash
python cli.py cancel-book 10
Бронювання місця в поїздці з ID 10 успішно скасовано.
```
якщо ж заброньованих місць не має, буде виведенно: 
 ```bash
python cli.py cancel-book 10
Не вдалося скасувати бронювання місця: в поїздці з ID 10 немає заброньованих місць.
```

**stat** виводить кількість поїздок та загльну кількість вільних місць
 ```bash
python cli.py stat          
(10, 165)
```
